# An-LLM-Driven-Automated-Simulation-Model-Generation-Method-for-Manufacturing-Systems
This repository provides a subset of the training data used in our study. Due to commercial confidentiality restrictions, the complete dataset cannot be made publicly available. Only a portion of the training data is released to support research transparency and reproducibility.
This repository provides the following resources for the proposed automated simulation model generation method:
1、Two trained LLM models.
2、Training code.
3、Partial LLM training dataset.
4、Partial YOLO training dataset.
